## 📌 Overview

**Nature's Platter** is a modern, responsive landing page built for an online grocery store. It displays fresh products, daily essential offers, customer service benefits, and a newsletter subscription layout designed with a clean visual interface.

🔗 **Website URL:** [https://fahimrahat58.github.io/Nature-s-Platter/](https://fahimrahat58.github.io/Nature-s-Platter/)

---

## ✨ Features & Sections

- **Hero Banner:** Engaging headline with visual graphics for grocery promotional deals.
- **Service Highlights:** 24/7 Support, Fast Delivery, and 100% Healthy Product section blocks.
- **Popular Products Grid:** Clean product showcase displaying discount badges, pricing, and ratings.
- **Arrivals & Discounts:** Highlighted promo banners for specific brands and products (up to 40% OFF).
- **Newsletter Subscription:** Custom input form block for collecting user email signups.
- **Fully Responsive Layout:** Fully customized using Tailwind CSS to render nicely on mobile, tablet, and desktop viewports.

---

## ⚡ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (Utility-First Framework)
